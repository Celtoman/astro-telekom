# Платформа партнерских сайтов

Словарь доменных терминов для управления контентом, публикацией и статической витриной партнерского сайта.

## Публикация контента

**Рабочая версия**:
Текущее сохраненное состояние контента в CMS, которое еще не обязано быть доступно посетителям сайта.
_Избегать_: Черновик, если сущность имеет статус `PUBLISHED`; текущая публикация

**Рабочая ревизия сайта**:
Последовательный номер изменения рабочей версии одного сайта. Один номер объединяет изменение сущности, запись аудита и создаваемый из него снимок публикации.
_Избегать_: Версия сборки, версия приложения

**Снимок публикации**:
Неизменяемый полный каталог сайта, зафиксированный из одной рабочей ревизии и переданный в конкретную пересборку.
_Избегать_: Живые данные, последний каталог

**Опубликованная версия**:
Последний снимок публикации, для которого внешний deployment завершился успешно. Только это состояние считается доступным посетителям.
_Избегать_: Рабочая версия, запрошенная версия

**Пересборка сайта**:
Фоновая операция, которая собирает весь статический сайт из одного снимка публикации и заменяет текущий release только после успешной проверки.
_Избегать_: Сохранение, частичная сборка
