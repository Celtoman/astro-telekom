# Платформа партнерских сайтов

Словарь доменных терминов для управления контентом, публикацией и статической витриной партнерского сайта.

## Публикация контента

**Рабочая версия**:
Текущее сохраненное состояние контента в CMS, которое еще не обязано быть доступно посетителям сайта.
_Избегать_: Черновик, если сущность имеет статус `PUBLISHED`; текущая публикация

**Рабочая ревизия сайта**:
Последовательный номер сохранения рабочей версии сайта и связанного аудита. Сохранение само по себе не создаёт публичный выпуск. У редакционных материалов есть собственные ревизии; редакционный выпуск фиксирует точный выбранный набор поверх обслуживаемого снимка.
_Избегать_: Версия сборки, версия приложения

**Снимок публикации**:
Неизменяемый каталог для конкретной публикации. Общая CMS-публикация фиксирует рабочий каталог сайта; редакционная сохраняет обслуживаемую основу и накладывает выбранные редакции и явные зависимости. Сборка читает этот снимок, а не незавершённые рабочие правки.
_Избегать_: Живые данные, последний каталог

**Опубликованная версия**:
Последний успешно подтверждённый в SQL снимок публикации. При `REBUILD_PROVIDER=static` результат активации независимо сверяется с сохранённым подтверждением контроллера (durable receipt). Успешный deployment кода сам по себе не подтверждает публикацию данных.
_Избегать_: Рабочая версия, запрошенная версия

**Обслуживаемая версия**:
Снимок, который фактически отдаёт Caddy. При неопределённом исходе активации он может опережать SQL-подтверждение; идентичность снимка проверяется через закрытый контроллер и receipt той же операции.
_Избегать_: Последняя рабочая ревизия

**Пересборка сайта**:
Фоновая операция, которая собирает статический сайт из одного снимка, проверяет артефакт и атомарно активирует его. Завершение требует подтверждённого результата; потеря ответа не разрешает считать операцию успешной или начинать второй выпуск.
_Избегать_: Сохранение, частичная сборка

Подробный действующий контракт — [публикация](docs/publication.md); реализация и ограничения — [current-state.md](docs/current-state.md).

## Наследование контента

Эти термины относятся к сохраняемому legacy-разрешению контента общих страниц. Текущие HOME/CITY_HOME используют собственные шаблоны и глобальные значения сайта; целевую модель задаёт [продуктовый контракт](docs/product-contract.md), а остаток legacy-очистки — [#196](https://github.com/Celtoman/astro-telekom/issues/196).

**Уровень контента**:
Область, в которой задано значение: провайдер, сайт, регион, город, страница или тариф. Более узкий уровень имеет приоритет над более общим.
_Избегать_: Версия контента, слой интерфейса

**Эффективный контент**:
Итоговое публичное значение после разрешения всех применимых уровней контента для конкретной страницы или тарифа.
_Избегать_: Исходный JSON сущности, опубликованная версия
