# План первого рабочего прототипа

## Этап 1. Основа

- Monorepo и Docker Compose.
- PostgreSQL, Redis, Prisma и миграции.
- NestJS API с авторизацией и ролями.
- Astro-сайт с базовым layout, SEO и маршрутом Казани.

## Этап 2. Данные и админка

- Provider, Site, Region, City.
- Страницы и библиотека блоков.
- Тарифы Дом.ру для Казани.
- SEO-поля и наследование.
- Ручное создание и редактирование тарифов.

## Этап 3. Публичный путь пользователя

- Главная Казани.
- Интернет, интернет + ТВ, ТВ.
- Карточка тарифа.
- FAQ и поддержка.
- Проверка адреса через адаптер API.
- Положительный, отрицательный и аварийный сценарии проверки.

## Этап 4. Заявки и CRM

- Форма заявки.
- Сохранение полного контекста заявки.
- Email на общий адрес.
- CRM на отдельном поддомене.
- Статусы и история изменений.
- Роли администратора, редактора, менеджера тарифов и оператора.
- Выдача ролей, деактивация пользователей и сброс сессий из админки.

## Этап 5. Публикация и контроль

- Sitemap, robots.txt, canonical и JSON-LD.
- Карточки тарифов по каноническому пути `/kazan/{tariff-slug}/`.
- Яндекс Метрика и события телефонов/форм.
- Пересборка страниц после изменения данных.
- Проверка исходного HTML, ссылок, кодов ответа и мобильной скорости.
- Резервное копирование PostgreSQL.
