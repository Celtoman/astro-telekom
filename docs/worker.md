# Фоновые задачи

Worker слушает Redis и обрабатывает две очереди:

## `tariff-imports`

Передает данные в `POST /api/v1/admin/tariffs/import`. Задача содержит `providerId`, `cityId` и массив тарифов. Для вызова используется `ADMIN_API_TOKEN`.

## `site-rebuilds`

Отправляет webhook после изменения данных. URL задается через `REBUILD_WEBHOOK_URL`. На первом этапе webhook может запускать сборку Astro-сайта в deployment-среде.

Административные изменения API также отправляют событие на этот webhook напрямую, поэтому production может подключить очередь worker или внешний deployment hook без изменения публичного сайта.

Если webhook не задан, задача помечается выполненной с результатом `skipped`, а публичные страницы не пересобираются автоматически.
