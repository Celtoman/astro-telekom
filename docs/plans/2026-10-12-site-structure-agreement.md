# Структура сайта: сводка согласования 12 октября 2026 года

Основа: действующий сайт владельца [tarify-dom.ru](https://tarify-dom.ru/) и [его исследование](../research/2026-10-12-tarify-dom-site-structure.md).

Статус: решения по типам страниц записаны по ответам владельца. Сводка предназначена для проверки состава целиком. Юридические страницы пока сохраняют прежний проектный контракт и отдельно в этой сессии не подтверждены. Окончательные URL, меню, состав блоков и выпуск новой структуры ещё не утверждены. Документ не описывает фактическую реализацию.

## Общая главная

Общая главная `/` сохраняется из действующего контракта как вход в сайт. Её состав блоков будет переработан и согласован отдельно. Тарифный каталог относится к локации.

## Внутри каждой локации

| Страница | Решение |
| --- | --- |
| Основная страница локации | Сохраняется одна основная страница; категории интернета/интернета+ТВ/ТВ не становятся самостоятельными страницами. |
| Страницы конкретных тарифов | Сохраняются по действующему контракту. |
| Проверка подключения по адресу | Добавляется отдельная страница внутри каждой локации. |
| Техподдержка | Добавляется отдельная страница внутри каждой локации. |

## Не входят в текущий согласованный состав

- Самостоятельные городские категории интернета, интернета+ТВ и цифрового ТВ.
- Общая страница проверки подключения по адресу и общая страница техподдержки: вместо них согласованы отдельные страницы внутри локаций.
- Страницы отдельных моделей роутеров и ТВ-приставок.
- Блог и отдельные страницы его статей — пока отложены.
- Каталог дополнительных услуг и отдельные страницы услуг — пока отложены.
- Самостоятельная страница «Способы оплаты»: информация об оплате размещается в «Личном кабинете» и FAQ; точный контент и блоки ещё не утверждены.
- Отдельные HTML-карты локаций: выбран вариант одной общей HTML-карты сайта.

## Осталось согласовать

1. Подтвердить в новом составе прежние три юридических документа: политику конфиденциальности, согласие на обработку персональных данных и политику cookie.
2. Проверить сводку состава целиком; точные URL и соответствия старых и новых адресов утверждаются отдельно.
3. После структуры согласовать меню и блоки страниц. Решения о типах страниц не утверждают размещение блоков или их контент.

Системные `/robots.txt`, XML sitemap и ответ 404 сохраняются из действующего контракта; это не дополнительные содержательные разделы.
