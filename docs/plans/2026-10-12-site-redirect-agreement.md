## Согласовано

## Предложение 1: старые общие проверка адреса и поддержка

Старые URL не содержат локацию. В новой структуре обе функции имеют отдельные страницы внутри каждой локации. Назначать произвольный город этому переходу не согласовано.

Вариант А, рекомендованный: оба адреса ведут HTTP 301 на сохранённый каталог локаций `/goroda-obsluzhivaniya-domru`, где посетитель может выбрать свою локацию. Вариант Б: оба адреса ведут HTTP 301 на общую главную `/`. Выбор перехода после определения локации, подписи ссылок и блоки не задаются этим решением.

| Старый path | Вариант А | Вариант Б | Статус |
| --- | --- | --- | --- |
| `/podklyuchenie-po-adresu` | `/goroda-obsluzhivaniya-domru` | `/` | Не утверждено |
| `/tekhpodderzhka-dom-ru` | `/goroda-obsluzhivaniya-domru` | `/` | Не утверждено |

## Предложение 2: пять страниц моделей оборудования

Вариант А, рекомендованный: HTTP 301 на общую страницу соответствующего оборудования. Это приводит посетителя в сохранённый раздел нужного типа оборудования. Вариант Б: HTTP 410 без страницы модели и без перенаправления. Дальнейший контент общих страниц и способы заказа согласуются отдельно.

| Старый path | Вариант А: целевой path | Вариант Б | Статус |
| --- | --- | --- | --- |
| `/oborudovanie/wi-fi-router-tp-link-ex220` | `/wifi-router` | HTTP 410 | Не утверждено |
| `/oborudovanie/wi-fi-router-tp-link-ec220-g5` | `/wifi-router` | HTTP 410 | Не утверждено |
| `/oborudovanie/wi-fi-router-dom-ru-wave-ax1500` | `/wifi-router` | HTTP 410 | Не утверждено |
| `/oborudovanie/wi-fi-router-d-link-dir-842-r7` | `/wifi-router` | HTTP 410 | Не утверждено |
| `/oborudovanie/tv-pristavka-movix-pro-2023` | `/movix` | HTTP 410 | Не утверждено |

Все пять старых страниц и две целевые общие страницы проверены в исходном исследовании с HTTP 200. Свежая техническая приёмка redirects выполняется после отдельной реализации и публикации; таблица не является такой приёмкой.
