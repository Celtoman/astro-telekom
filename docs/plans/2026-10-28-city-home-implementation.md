# Внедрение согласованной городской страницы

**Цель:** реализовать полный контракт [Q1–Q38](2026-10-28-city-home-contract.md), CMS и preview, выполнить commit/push/deploy и проверить действующий защищённый test-контур. Решение о реальном трафике остаётся у владельца.

**Архитектура:** версия CITY_HOME 3 хранит фиксированные десять блоков в независимом шаблоне города. Общие факты сайта имеют типизированный источник, данные тарифов — общую TariffView. Публичная страница и preview используют одни проекции/рендереры. Исторические immutable snapshots сохраняются; миграция меняет рабочий источник и явно повышает ревизию, активация CMS выполняется отдельно от выпуска кода.

**Стек:** Astro 7 / TypeScript / NestJS / Prisma 7 / PostgreSQL / существующий plain CSS публичного сайта; React и React Aria в CMS. Новые зависимости не предполагаются. Работа в текущем master по поручению владельца; чужие незакоммиченные изменения сохраняются.
