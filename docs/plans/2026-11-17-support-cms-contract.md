# SUPPORT — контракт редактора CMS

17 ноября 2026. Q10–Q17 согласованы владельцем. Редактор реализуется в действующем стиле уже выпущенных страниц проекта. Черновик кода не считается реализацией или подтверждением этого контракта.

## Согласовано

- Один шаблон для всех городов; город, телефоны и графики подставляются из общих данных проекта.
- Все содержательные тексты SUPPORT редактируются. Состав и порядок секций, карточек и шагов фиксированы; шрифты, цвета, отступы, иконки и адаптивы системные.
- Семь подписей быстрых ссылок относятся к содержанию страницы; их якорные назначения формируются автоматически.
- Общие Header/Footer и AddressOnly используют общие компоненты. Локальные поля копии адресной формы, внесённые в ранний черновик, не входят в согласованный редактор SUPPORT. Системные подписи действий не переопределяются из SUPPORT.
- Фото и скриншоты страницы разрешено заменять, редактировать их альтернативные описания и существующие подписи. Логотипы и иконки системные. Подписи в новых местах макета не добавляются.
- Внешние ссылки сообществ и магазинов приложений редактируются. Телефонные ссылки используют номера из настроек.
- FAQ поддержки самостоятельный. Первоначальные вопросы сохраняются из Screens, ответы берутся на эти же вопросы из действующего городского FAQ вместе с переменными. Дальнейшие изменения FAQ поддержки не меняют CITY_HOME FAQ.

## Согласованные правила редактирования и работы

1. Q14: редактирование фрагментов текста и inline-ссылок через ограниченный редактор; внутренние назначения выбираются из согласованного списка, телефон — из системного контакта. Начальные цели: главная, проверка подключения выбранного города, города обслуживания, обзор официального сайта, обзор личного кабинета, проверка скорости, FAQ поддержки.
2. Q15: замена изображения загрузкой файла через CMS, описание, существующая подпись и предпросмотр; выделение используемой области для четырёх кадров инструкций (два callback и два chat) и увеличения номера. Телефонный полный снимок всегда показывается целиком; увеличение строится из выбранного фрагмента того же источника, самостоятельный файл увеличения не вводится. Для остальных изображений сохраняется полный показ в принятой композиции и мокапе.
3. Q16: FAQ позволяет добавлять, удалять и переставлять записи; безопасный черновик может быть неполным, для публикации нужны 1–50 полных пар вопрос/ответ.
4. Q17: редактор по разделам страницы с ручной кнопкой сохранения; сохранённая рабочая версия доступна в предпросмотре выбранного города, публикация выполняется отдельно. Ошибки указывают на конкретные поля, неполный черновик не допускается к выпуску. Конфликт ревизий сохраняет введённые данные.

## Исходный срез перед реализацией

Есть Tiptap-редактор новостей с выделением и ссылкой, но он привязан к NewsBodyNode. Общего выбора inline-направлений нет. Есть новостная загрузка изображений и crop cover/social, но она привязана к новостному media API и фиксированным пропорциям; для SUPPORT нужна адаптация. Существующий общий preview использует сохранённую версию и отключает формы/ссылки. Эти возможности не объявляются уже готовым редактором SUPPORT.
