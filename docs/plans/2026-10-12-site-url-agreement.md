# URL сайта: сохранение адресов и новые маршруты

Дата: 12 октября 2026 года. Основа: [согласованный состав страниц](2026-10-12-site-structure-agreement.md), [исследование действующего сайта](../research/2026-10-12-tarify-dom-site-structure.md) и ответы владельца.

Статус: **сохраняемые страницы оставляют действующие URL** — решение владельца. Адреса новых страниц и назначения перенаправлений ниже пока являются предложениями. Это документ согласования, не описание реализованных маршрутов и не разрешение публиковать изменения.

## Принятое правило

URL существующих страниц, которые входят в новую структуру, сохраняются. Предварительные альтернативные пути из старого канона не заменяют адреса источника. В частности, `/faq`, `/wifi-router`, `/policy`, `/soglasie` и `/lichnyy-kabinet-dom-ru` не переименовываются ради общего правила оформления slug.

Новые адреса нужны для новых страниц и перенесённых внутрь локаций функций. Для страниц источника, чьи типы исключены либо разделены, назначения redirects согласуются отдельно. Выбор правила не запускает перенос данных, изменение приложения или публикацию.

## Сохраняемые адреса

| Страница | Действующий path |
| --- | --- |
| Общая главная | `/` |
| Основная страница локации | Действующий URL каждой локации, например `/kazan` и `/moscow`. |
| Страница конкретного тарифа | Действующий полный URL, например `/kazan/giga-300-internet`. |
| Общий тариф кабельного ТВ | `/kabelnoe-televidenie-obshhij-tarif` |
| Общий тариф цифрового ТВ | `/cifrovoe-televidenie-obshhij-tarif` |
| Города обслуживания | `/goroda-obsluzhivaniya-domru` |
| Роутеры | `/wifi-router` |
| Movix | `/movix` |
| Вопросы и ответы | `/faq` |
| Проверка скорости | `/proverit-skorost-interneta` |
| Личный кабинет | `/lichnyy-kabinet-dom-ru` |
| Официальный сайт Дом.ру | `/official-site-domru` |
| Политика конфиденциальности / обработки персональных данных | `/policy` |
| Согласие на обработку персональных данных | `/soglasie` |
| Политика cookie | `/politika-obrabotki-faylov-kuki` |
| Архив новостей | `/novosti` — дополнительно проверен, HTTP 200. |
| Архив акций и скидок | `/akcii-i-skidki` — дополнительно проверен, HTTP 200. |
| Существующие новости и акции | Полные действующие URL, включая `/novosti/{slug}`, `/akcii-i-skidki/{slug}` и `/bez-rubriki/{slug}`. Классификация публикации не меняет её URL автоматически. |

Исходный объявленный реестр — [sitemap-urls.csv](../research/evidence/2026-10-12-tarify-dom-structure/sitemap-urls.csv). Он является датированным срезом, а не доказательством HTTP-доступности каждого экземпляра. Три юридических страницы проверены отдельно по ссылкам Footer. Существующие полные URL тарифов и городов переносятся с явным соответствием сущности, без автоматического переписывания slug по названию.

Сосновый Бор имеет исключение: город `/sosnovyj-bor`, часть тарифов под `/sosnoviy-bor/…`. Решение сохранять URL не разрешает автоматически исправить эти адреса или сопоставлять города только по префиксу тарифа. Для реализации требуется явная карта соответствий сущностей и адресов.

## Предложения для новых страниц

Вариант А рекомендован; варианты ещё не утверждены. `{location}` означает действующий адресный slug основной страницы локации.

| Страница | Вариант А | Вариант Б | Причина рекомендации |
| --- | --- | --- | --- |
| Проверка подключения внутри локации | `/{location}/proverka-adresa` | `/{location}/proverka-podklyucheniya-k-domru-po-adresu` | Короткий адрес ясно обозначает проверку адреса. |
| Техподдержка внутри локации | `/{location}/tehpodderzhka` | `/{location}/tehpodderzhka-domru` | Короткий адрес с явной привязкой к локации. |
| Общая карта покрытия | `/karta-pokrytiya` | `/karta-pokrytiya-provaydera` | Короткое название соответствует назначению страницы. |
| Контакты партнёра | `/contacts` | `/kontakty` | Сохраняет предварительный путь, уже используемый в документации проекта. |
| Общая HTML-карта сайта | `/sitemap` | `/karta-sayta` | HTML `/sitemap` и системный XML `/sitemap.xml` имеют разные адреса. |

Проверка кандидатов: первые варианты двух городских страниц проверены на Казани; общие `/karta-pokrytiya`, `/contacts`, `/sitemap` проверены непосредственно. Они вернули HTTP 404. Общие альтернативы `/karta-pokrytiya-provaydera`, `/kontakty`, `/karta-sayta` также вернули 404. В исходном sitemap нет двух городских суффиксов варианта А у всех 207 перечисленных городов; это не HTTP-проверка каждого города. Городские альтернативы варианта Б не открывались отдельно. Коллизии рабочего каталога новой платформы этой проверкой не подтверждены и не исключены.

## Адреса исключённых или разделённых страниц

| Старый адрес | Почему требуется отдельное решение | Текущий статус |
| --- | --- | --- |
| `/akcii-domru` | Смешанный список новостей и акций разделяется на два самостоятельных раздела; доступны существующие `/novosti` и `/akcii-i-skidki`. | Предлагается 301 на `/akcii-i-skidki`; альтернатива — `/novosti`. Назначение не утверждено. |
| `/podklyuchenie-po-adresu` | Общая проверка заменяется страницами внутри локаций; старый URL не указывает локацию. | Назначение redirect или другой переходный сценарий не утверждены. Нельзя выбрать произвольный город автоматически. |
| `/tekhpodderzhka-dom-ru` | Общая поддержка заменяется страницами внутри локаций; старый URL не указывает локацию. | Назначение redirect или другой переходный сценарий не утверждены. |
| Пять `/oborudovanie/{equipmentSlug}` | Страницы моделей оборудования не входят в текущий состав. | Соответствия общим страницам роутеров/Movix предстоит согласовать. |
