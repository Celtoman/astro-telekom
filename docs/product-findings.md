# Продуктовые и UX/UI-находки

Этот документ — входящий реестр наблюдений и идей, обнаруженных во время выполнения технических задач. Здесь фиксируются продуктовые проблемы, UX/UI-риски, дизайн-наблюдения и предложения по улучшению до отдельного обсуждения с владельцем продукта.

Запись в этом файле не означает согласованного решения и не подтверждает наличие дефекта в коде:

- подтвержденная техническая проблема оформляется GitHub Issue с label `tech-debt`;
- согласованное продуктовое решение переносится в [decisions.md](decisions.md);
- согласованная работа оформляется отдельным GitHub Issue с label `task`;
- после переноса исходная находка остается в реестре со ссылкой и итоговым статусом.

## Статусы

- `NEW` — находка зафиксирована и ожидает обсуждения;
- `DISCUSSED` — обсуждена, но решение не принято;
- `ACCEPTED` — направление согласовано, требуется оформить решение или задачу;
- `REJECTED` — осознанно отклонена с зафиксированной причиной;
- `CONVERTED` — перенесена в `decisions.md` и/или GitHub Issue.

## Формат записи

```md
### PF-001 — Краткое название

- Дата:
- Область: product | UX | UI | design | content | analytics
- Статус: NEW
- Контекст:
- Наблюдение:
- Возможное влияние:
- Идея или гипотеза улучшения:
- Вопросы для обсуждения:
- Связанные решения/issues:
```
