Изменения разрешены владельцем после аудита. Статус: TEST RELEASED, a09c2c71. [Внешняя проверка](2026-11-07-news-fix-test-release.md) завершена; оставшиеся реальные черновики не публиковались.

## Поведение

- Общий `main` остаётся владельцем 24 px после шапки; новостная страница не добавляет второй margin. Список, статья и категория используют одно правило.
- Карточки сохраняют единую ссылку, полный текст и выравнивание ролей внутри ряда. Hover #e0231e/#f6f7f9, Pressed #c61f1a/#ffeae9; внешняя рамка фокуса без сдвига. Padding 24 px Desktop, 16 px Tablet/Mobile. Hover применяется только при наличии указателя с hover.
- Для трёх и двух колонок наличие фото определяется независимо в каждом ряду. В смешанном ряду у карточки без фото есть библиотечная тематическая заглушка; полностью текстовый ряд не резервирует media. На Mobile заглушка скрыта, фото остаётся необязательным; grid-row сбрасывается. Библиотечный слот «Роутер» CMP-0016 использует существующий Phosphor broadcast, а для тарифов добавлен точный SVG Wallet из UI Library с лицензией MIT.
- `NewsAdminContext` и редакционный индикатор получают точный настроенный сайт с сервера, без выбора и без доверия к siteId из query. Внутренние API, recovery и операции сохраняют site scope. Список, редактор, категории, настройки новостей и 404 открываются без выбора сайта. Другие разделы админки не перерабатывались.
- В списке есть чекбоксы DRAFT, выбор всех черновиков текущей страницы, счётчик, снятие выбора и общий review. При смене фильтра/страницы выбор очищается с сообщением. Неподготовленный материал блокирует весь выбранный набор и даёт ссылку на редактор.
- Batch candidate использует один serving baseline, точные редакции и дедуплицированные категории-зависимости. Создаются одна SitePublication, несколько editorialItems и один enqueue. Существующая очередь дедуплицирует повтор по publicationId; отдельного цикла сборок по статьям нет. Повтор operationId возвращает ту же публикацию. ACK обрабатывает каждую захваченную редакцию, не публикуя более новый autosave или невыбранные материалы.
- Потеря ответа не запускает новую операцию: продолжается polling прежнего идентификатора, повторяется тот же запрос. Подтверждённый терминальный результат очищает устаревшую ошибку связи и review. Ключ операции хранится с изоляцией user/site; недоступность localStorage объясняется явно.

## Проверки

- Изолированный PostgreSQL: одна публикация с двумя ARTICLE ledger items и одной зависимостью, идемпотентный повтор; ACK обеих выбранных редакций, третья осталась черновиком. Сценарий включён в существующий category retirement rehearsal, который также сохраняет проверки переноса/aliases/legacy revisions.
- Профильные API/renderer/context тесты прошли. Финальный `pnpm check` завершился успешно: 1069 pass / 0 fail / 1 skip, 476658 ms. Единственный пропуск — файловая symlink недоступна без Windows privilege; Linux rehearsal соответствующей защиты остаётся в общем наборе.
- Свежий immutable артефакт `fe6e5f97203f739c8ee6fe47e42ed163f7c4e90be1be7888dd98b09beef5bfe5`: Chromium проверил список/статью/категорию на 1440/834/390/320. Во всех 12 сочетаниях gap после шапки 24 px, горизонтального переполнения нет; padding 24/16/16/16. Полностью текстовый набор не имеет медиазон. Hover, удержание указателя, focus-visible 2 px и Enter соответствуют контракту.
- Дополнительная контентная матрица того же renderer/CSS: шесть карточек, фото только у третьей. Видимые медиазоны на 1440/834/390/320: 3/2/1/1; текстовые ряды не получают резерва от другого ряда, размеры внутри широкого ряда совпадают. Синтетическая обложка — тестовый asset, не контент новости.
- Собранная админка проверена с синтетическими HTTP-ответами: выбор клавиатурой и указателем двух материалов, один POST публикации, намеренно потерянный ответ и последующий SUCCEEDED. После результата нет диалога, alert и сохранённого pending key. Неполный третий черновик даёт ссылку `/news/edit?id=c` и не создаёт второй POST. На четырёх ширинах нет переполнения и selector сайта; навязанный `siteId=foreign` не используется. Это проверка UI/транспортного восстановления на fixture, не публикация в живую БД; реальный backend/ACK отдельно проверен PostgreSQL rehearsal.
- Восстановление операции выдержало перезагрузку страницы: pending key найден, новый запуск заблокирован, POST остался единственным. Диалог не переполняется на четырёх ширинах; Escape возвращает фокус на кнопку запуска.
- Проверен SPA-переход из общего раздела при нескольких сайтах в новости: недоступный legacy-индикатор заменяется корректным контекстом Дом.ру без ручного обновления. Shell задаёт индикатору ключ user/scope и явный editorial prop; старый экземпляр не может перезаписать новый контекст ответом запоздавшего запроса. Внутри редакционного раздела лишнего перемонтирования нет.
- Независимое code review проверило одну публикацию/очередь, совместимость ACK и обнаружило пограничные ошибки: конфликт @preserve подтверждённых aliases и устаревшее сообщение после потерянного ответа. Исправлены, alias regression добавлена. Ошибки проверки и запуска сохраняют entityId и переход к конкретному черновику.
- Первый полный gate обнаружил [#559](https://github.com/Celtoman/astro-telekom/issues/559): guard числа тестов ошибочно трактовал serving baseline и CMS revisions в ранее существующей architecture.md. Уточнён именно контекст объявления тестового baseline, положительные проверки запрета сохранены, добавлен отрицательный regression; профиль ci-runtime прошёл.
- Промежуточный прогон по изменяемому рабочему дереву не засчитан: во время него агент правил shared preview, и guard корректно остановил build при смене renderer; runtime rehearsal также завершился timeout. Последующие проверки выполнены по неизменяемым экспортам. Предыдущий полный экспорт прошёл; после последней правки SPA-индикатора весь gate повторён по окончательному staged tree `f9559a99d4782f126697eb0cc53802da85ca8f6b`. В нём lint, Prisma validate, demo build и все тесты выполнены без отключений; существующие неизменённые зависимости подключены junction, автоматическая переустановка pnpm в экспорт отключена через `pnpm_config_verify_deps_before_run=false`. После gate меняются только итоговые записи документации.

Браузерные результаты этого отчёта относятся к локальному синтетическому артефакту; последующая внешняя проверка вынесена в отдельный отчёт выше. Safari, физический touch и ручной screen reader не заявляются. Инкрементальная сборка не реализуется: публикация выбранного набора сохраняет одну полную статическую сборку и атомарную активацию. Измерение ускорения полного внешнего контура остаётся отдельным решением.

Локальные скрипты и журналы: `.codex-tmp/news-fix-558/`; они не содержат рабочих credentials и не входят в релиз. Исходные незакоммиченные документы владельца сохраняются; в commit включаются только изменения этой задачи.
