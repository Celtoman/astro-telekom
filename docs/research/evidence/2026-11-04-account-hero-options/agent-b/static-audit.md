# Статический аудит Hero B

Статус: **renderer подготовлен; четыре нативных PNG просмотрены, см. review.md**. Композиция и адаптивность без критических замечаний. Ошибка цвета CTA исправлена координатором и закрыта повторным просмотром обновлённых D/320: белая надпись без подчёркивания. Figma/API автором B не вызывались.

`node --check hero.js` завершился успешно после подготовки renderer.

Применимые проверки UX: распознаваемость назначения, ранний переход на официальный сервис, отсутствие ложной формы, понятный порядок справочного материала. Loading/error/empty локально не проектируются: Hero не отправляет форму и не принимает реквизиты. Для реализации нужны нативная ссылка CTA, видимый keyboard-focus, логичный порядок H1/lead/CTA/figure/справочные абзацы, alt исходного изображения и реальный доступ к увеличению. Скриншот не подтверждает работу клавиатуры, screen reader или WCAG.
