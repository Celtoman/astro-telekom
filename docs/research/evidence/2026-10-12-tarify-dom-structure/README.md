# Срез структуры tarify-dom.ru

Дата: 12 октября 2026 года. Источник: прямые публичные HTTP GET; sitemap-реестр разобран по `url/loc` namespace `http://www.sitemaps.org/schemas/sitemap/0.9`.

- `sitemap-urls.csv`: все 4094 записи восьми дочерних sitemap, включая повторяющуюся запись; 4093 уникальных URL. `http_status=NOT_CHECKED` означает только наличие в sitemap, без HTTP-проверки экземпляра.
- `checked-pages.csv`: 44 отдельно прочитанных HTML-адреса, конечный URL, HTTP-статус, canonical, H1 и H2. Из них 42 вернули 200 и два пробных адреса — 404. Три юридические страницы включены сюда по ссылкам Footer, хотя в sitemap их нет.
- `url-candidates.csv`: отдельное дополнение при согласовании URL — 10 GET-наблюдений. Архивы `/novosti` и `/akcii-i-skidki` вернули 200; восемь кандидатов новых адресов вернули 404. Этот файл не изменяет исходный sitemap и счётчики первоначального прохода.

Это датированный срез. Не доказывает индексирование, актуальность тарифных характеристик, работу интерактивных форм или доступность всех объявленных URL. Число записей sitemap не равно числу подтверждённых доступных HTML-страниц. Метод, выборка и интерпретация — в [отчёте](../../2026-10-12-tarify-dom-site-structure.md).
