Обнаружено и исправлено до передачи координатору:

- В шагах оплаты/паузы/обещанного платежа собственный номер-бейдж мог дублироваться генерируемым префиксом LI. В AStepPara префикс отключён, исходные слова не менялись. Нумерация остаётся один раз в последовательном бейдже.
- В recovery точное сравнение текста description могло не найти внутренний TEXT из-за завершающего перевода строки. Сравнение делается trim(), что повышает устойчивость сохранения исходных ссылок.
- У навигации длинные исходные вопросы преобразованы в короткие названия тем, чтобы не получить снова1000px оглавление. Точные исходные подписи остались в метаданных, содержательные заголовки разделов не сокращены.
- В адресной форме скрыт необязательный декоративный бейдж «за пару секунд», чтобы не добавлять новой временной гарантии. Полный текст исходного виджета7 сохранён.

Остаточные риски рендера: reflow вложенных библиотечных step/FAQ/address при длинном исходном тексте; wrap nav «Обещанный платёж» на320; источник поддерживает legacy href для отправки заявки. Эти пункты требуют реального просмотра экспортов, не являются подтверждёнными дефектами. Отдельных параллельных Figma-вызовов не выполняю по указанию координатора.
