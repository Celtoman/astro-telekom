# A: визуальная проверка Tablet720 и Mobile358

Просмотрены актуальные PNG всех15 ключей из exports-final. Для длинных блоков сделаны и просмотрены парные фрагменты по1300px в responsive-review-crops; масштаб пикселей не уменьшался. Новых Figma/API-вызовов не было.

| Ключ | Tablet720 / Mobile358 — фактический результат |
|---|---|
| navigation |3 и2 колонки соответственно; длинная тема переносится, соседние плитки имеют общую высоту. |
| login |Карточки способов и отдельная группа данных складываются последовательно; текст и предупреждение не перекрываются. |
| recovery |Четыре способа читаются отдельно, номера и заголовки помещаются; ссылки различимы. |
| registration |Три канала и пояснение после договора видны; длинные названия карточек переносятся без обрезки. |
| address |НаTablet декоративного изображения нет; заголовок, intro, поле, CTA и дата сохранены. Текстовая часть сохраняет более узкий measure, справа остаётся свободное место; это плотностный компромисс готового блока, не клиппинг. |
| features |Три полных функциональных группы, затем изображение; подпись/увеличение стоят у соответствующего изображения. |
| overview |Обе области интерфейса и все поясняющие группы видны. Самый объёмный A-модуль; тонкий верхний скриншот требует увеличения. |
| payment |Два шага, изображение и способы оплаты остаются разными смысловыми группами. |
| promised |Условия отделены от алгоритма, каждый шаг имеет только один номер, длинный второй шаг не обрезан. |
| termination |Оба шага и изображения видны, правильная подпись меню и officehint после предупреждения подтверждены. |
| pause |Условия и6 последовательных шагов читаются без наложений; подпись относится к изображению приостановления. |
| interzet |Адрес и вход теперь до истории бренда, наT/M также до логотипа; основной путь доступен в начале. |
| business |Полоса входа сразу послеH2; длинное пояснение и изображение остаются ниже. |
| app |Store badges после короткого intro, до подробной инструкции помощи; они не растянуты. |
| faq |Все6 вопросов видны, длинные заголовки переносятся; три телефона первого ответа различимы как ссылки. |

По просмотренным PNG новых перекрытий, обрезки текста и расходящихся подписей не выявлено. Плотность и высота полных инструкций остаются tradeoff вариантаA. Это экспертная визуальная оценка, не реальный usability/keyboard/AT-тест.
