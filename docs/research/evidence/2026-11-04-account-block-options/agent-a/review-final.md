# Финальная визуальная проверка варианта A

Этот файл сохраняет предфинальные наблюдения до point-fix. Актуальный итог после исправлений — review-postfix.md; все15 ключей уже просмотрены на четырёх размерах.

Источник проверки: актуальные PNG из `exports-final`, не прежние crops. Desktop-файлы фактически имеют ширину1024px и являются масштабированным представлением фрейма1360; Mobile320 —288px контентной ширины. Длинные мобильные изображения просмотрены фрагментами по1400px без уменьшения.

Проверка экспертная и визуальная. Клики, клавиатура, фокус и исследование с участниками не проверялись. Ниже отмечены только реально просмотренные изображения.
