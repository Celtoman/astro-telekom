# Вариант C — сценарные модули

Автор: независимый агент C. Первый экран, Header/Footer и итоговая страница не изменяются. Это альтернативы отдельных блоков для выбора владельцем.

Изучены живые оригиналы и их Desktop-скриншоты: [HOME / Больше возможностей](https://www.figma.com/design/yMIEwjHa3SW9IkK26bMc6Y?node-id=35-51), [CITY / Оборудование](https://www.figma.com/design/wTUEawOZ8dTBwgzQSad8hw?node-id=21-27), [CITY / Каталог v2](https://www.figma.com/design/wTUEawOZ8dTBwgzQSad8hw?node-id=56-14), структура [CITY / Сравнение](https://www.figma.com/design/wTUEawOZ8dTBwgzQSad8hw?node-id=34-249). В первом — смысловые группы и разделители; во втором — компактные парные панели с продуктовой иллюстрацией; в третьем — чипы, внутренние группы параметров и ясная иерархия. Не копируется содержимое этих блоков.

Навыки: product-design-and-ux — одна задача и путь к ней у каждого модуля; impeccable — сознательные разные композиции в существующем мире бренда; interaction-design — явно разные якоря, внешние переходы и изображения; web-accessibility — порядок чтения, reflow и44/48px действия; design-critique/ux-audit — устранение excise бокового оглавления, распознавание групп вместо чтения статьи; emil-design-eng — размеры, выравнивание, ритм, smoothing0.6. Сессии с пользователями не проводились.

| Блок | Композиция C | Пользовательская причина |
|---|---|---|
| Оглавление | Компактное плоское облако коротких чипов с переносом | Сразу увидеть все темы без sidebar и дополнительных групповых заголовков; исходные длинные подписи сохранены в именах/описании |
| Вход | Три места входа как маршрут выбора; ниже типы учётных данных и изображение в отдельной зоне | Не смешивать «где войти» и «что ввести» |
| Восстановление | Начало восстановления и компактный экран слева, четыре сравнимые строки маршрутов справа | Сравнить все способы в одном модуле; рекомендация способа4 остаётся текстовой опорой, без большого hero способа4 и карточек альтернатив |
| Регистрация | Акцент «автоматически после подключения», три способа обращения, затем результат/документы | Снять ошибочное ожидание отдельной формы регистрации |
| Адрес | Готовая связанная адресная форма и компактная последовательность результата процесса | Объяснить назначение формы, не создавать новый input/lead-flow |
| Возможности | Три функциональных направления с отдельными строками операций; изображение после карты функций | Сначала увидеть, что можно сделать, затем сопоставить с кабинетом |
| Обзор | Два самостоятельных тура: верхнее меню и центральная страница; нумерованные пояснения возле изображений | Сохранять связь текста с номером на скриншоте |
| Оплата | Три фазы действий рядом с большим примером экрана | Понять порядок действий без последовательного чтения всех абзацев |
| Обещанный платёж | Условия отдельной группой, затем четырёхшаговый маршрут со скриншотом | Отделить право/стоимость от механики включения |
| Расторжение | Две крупные стадии с собственными иллюстрациями; обязательное предупреждение завершает модуль | Изображения принадлежат своим действиям, предупреждение не теряется между ними |
| Приостановление | Ситуация/условия рядом с изображением и шесть шагов ниже | Не путать временную приостановку с расторжением |
| Интерзет | Компактный маршрутизатор: история/бренд и выделенный адрес входа | Быстро попасть в свой кабинет; история остаётся вторичным объяснением |
| Бизнес | Выделенный адрес входа, две смысловые зоны назначения и иллюстрации, функциональный итог | Не смешивать аудиторию физлиц с корпоративным сценарием |
| Приложение | Установка и обращение за помощью как две стадии, исходная иллюстрация поддерживает маршрут | Показать, что делать после установки, не ограничиться рекламной картинкой |
| FAQ | Сетка полных ответов на существующих FAQ-элементах | Альтернатива аккордеону: можно сравнить ответы без раскрытий |

Текст основной части, условия, все подписи, изображения и ссылки не сокращаются. Дополнительные короткие названия — навигационные опоры, не новые условия услуги. На Mobile/320 все смысловые группы складываются в один столбец; никаких боковых панелей. Цена/дата исходника не объявляются актуальными фактами провайдера. Внешние реальные сценарии и клавиатурная реализация отдельно.
