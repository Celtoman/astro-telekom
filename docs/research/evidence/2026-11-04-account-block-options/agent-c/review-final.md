# Визуальная критика C по реальным экспортам

Проверены реальные PNG из exports-final, а не только дерево или renderer. Файлы не редактировались в процессе этого прохода; Figma API не вызывался.

Просмотрены **14 пар Desktop/Mobile320**: login, recovery, registration, address, features, overview, payment, promised, termination, pause, interzet, business, app, faq. Desktop-файлы имеют ширину1024(экспорт полного1360), Mobile320 — внутренние288px. Все длинные Mobile разрезаны на части по1400px в review-crops; для чтения просмотрены контактные листы без уменьшения ширины полос.

Также просмотрены старые navigation-C-Desktop/Mobile320 и navigation-comparison. В них зафиксирован перенос слов по буквам; renderer исправлен измерением реального labelGeist14+32px и HUG. **Повторного PNG navigation после исправления в этом проходе ещё нет**, визуальное прохождение исправления не заявляется.

Для11 ключей сравнены реальные A/B/C Desktop-силуэты через triptych: login, recovery, registration, features, payment, promised, termination, interzet, business, app, faq. Для address/overview/pause отсутствовал полный набор A/B-файлов в exports-final на момент сравнения; суждение о трёхсторонней отличимости по ним не заявляется.

## Значимые замечания

Это экспертные гипотезы и проверка выполнения дизайн-брифа, не наблюдения пользователей. Источник формулировок и коммерческих условий не переписывался.

## Что работает и чем отличается C

| Блок | Результат визуальной проверки | Трейдофф |
|---|---|---|
| recovery | Чётко отличается отA/B: начало и иллюстрация слева, четыре сопоставимые строки справа; recommendation4 видна текстом | На320 всё превращается в последовательное чтение2180px; это полная версия всех способов, не компактный fast path |
| features | Три функциональные строки: название направления слева, операции справа. Хорошо отличается от трёх вертикальных категорийA/B | Desktop-скриншот ниже матрицы крупный; Mobile-иллюстрация обзорная и требует увеличения для деталей |
| overview | Два цельных тура, номера действительно сопоставлены областям/пунктам изображения. Все типы материалов разделены | Mobile3710px — длинный полный разбор. Это осознанная альтернатива раскрытиям, не доказательство удобства длинной страницы |
| promised | Условия отделены от четырёх настоящих действий;4 карточкиC отличаются от компактного спискаA и четырёхколоночной нижней полосыB | Из-за большей высоты картинки справа в Desktop есть свободная область под условиями; читаемость не нарушена |
| pause | Ситуация и стоимость рядом с примером, затем6 действительных шагов. Их порядок читается | Содержательная фраза о«Расторжении» выглядит спорной, но это дословный источник; её исправление относится к отдельной редакционной проверке |
| business | Адрес входа сразу подH2; назначение и иллюстрация разделены, результат собран в нижней панели | В Mobile URL переносится по разделителям, но слова и домен не обрезаны |
| faq | C действительно иной:6 открытых полных ответов в двух колонках, без ложного минуса/аккордеона. Ссылки телефонов визуально выделены | На3202834px. Преимущество — отсутствие раскрытий, цена — длина; владелец может выбратьA/B для компактности |

Критических обрезок или переносов слов по буквам в просмотренных14 содержательных парах не заметил. Это визуальное наблюдение, не полная структурная или доступностная приёмка. Нумерация в реальных алгоритмах сохраняет смысл; нумерация альтернатив login требует исправления, а не механического повторного применения«шагов».

Клики, внешний вход, отправка адреса, keyboard/focus/AT не проверялись. Сессии с пользователями не проводились. Итоговая страница не собиралась. До выбора владельцем нельзя объявлять всеC-композиции принятыми или делать из этого набора единый шаблон.
