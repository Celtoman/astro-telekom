# T0: источник переноса

Проверено6ноября2026 через публичный WordPress REST API tarify-dom.ru с явным User-Agent. `X-WP-Total=10`, `X-WP-TotalPages=1` при per_page100; IDs повторного чтения совпали. Полные ответы временно сохранены в исключённой `.codex-tmp/news-implementation/`, а не помещены в публичный renderer.

-6публикаций категории62/`novosti` входят в перенос как NEWS.
-4публикации категории16/`akcii-i-skidki` исключены как акции.
- У источника одна используемая категория новостей: «Новости». Тематические категории DEMO не создаются автоматически.
-6обложек зарегистрированы отдельно в media-register.json; оригиналы и содержание переносятся только на этапе проверенного импорта.
- Слаги сохраняются. Полные старые адреса становятся pending301, новые — `/news/{slug}`. Публичные назначения до выпуска не активируются.
- Регистр содержит исходные даты/GMT, IDs автора и медиа, content SHA256, классификацию и назначение. Это инвентаризация, не импорт и не факт публикации.

Источник: https://tarify-dom.ru/wp-json/wp/v2/posts?per_page=100&_embed=1 . Машинное доказательство полноты — source-register.json/paginationEvidence.
