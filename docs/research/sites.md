## 1. tarify-dom.ru

Открыто: [федеральная главная](https://tarify-dom.ru/), [Казань](https://tarify-dom.ru/kazan), [Гига+ 300](https://tarify-dom.ru/kazan/giga-300-internet).

**Структура.** Федеральная главная ведет к городам через поиск, алфавит и список. Город — длинная посадочная страница. В городском меню интернет и интернет + ТВ ведут на `#internet` и `#internetTV`, а не на отдельные категории. Индивидуальные тарифы имеют вложенные адреса `/kazan/giga-300-internet` и аналогичные. Два телевизионных предложения ведут на общие `/kabelnoe-televidenie-obshhij-tarif` и `/cifrovoe-televidenie-obshhij-tarif`.

**Блоки федеральной страницы:** вводный экран → проверка адреса → выбор города → навигация по услугам/сервисам → информация об операторе и технологиях → преимущества → этапы подключения → стоимость подключения → тарифные линейки → оборудование → FAQ → новости/акции.

**Блоки города:** вводный экран с местными показателями → проверка адреса/консультация → подбор по потребностям → интернет + ТВ → интернет → ТВ → сравнительная таблица → этапы подключения → Movix → оборудование → преимущества → отзывы → города → контакты → FAQ. Подбор по устройствам и интересам присутствует в интерфейсе; точность алгоритма не проверялась.

**Блоки тарифа:** основные параметры/цена → оборудование → дополнительные возможности → описание → проверка адреса → другие тарифы города → FAQ по тарифу.

**Перелинковка:** федеральная → город; город → тариф; тариф → другие тарифы того же города; город → другие города; шапка/подвал → общая поддержка, FAQ, новости, личный кабинет и проверка адреса. Встречается действие открытия всплывающего окна через `#elementor-action...`: это интерфейсное действие, а не отдельная информационная страница.

**Нюанс:** исправление раннего обобщения в переписке — не все категории внутри города имеют отдельные URL. На этом сайте сосуществуют якорные категории и самостоятельные тарифы. Для нашей CMS нужны оба варианта вывода.

**Тариф:** параметры/цена → включенные услуги → оборудование → опции → заявка → описание → популярные тарифы того же города.

Карта города группирует ссылки по назначению. Встречается заголовок «МТС в других городах Москвы» — буквальный шаблон может создавать неестественную географическую формулировку.

**Для проекта:** разделить назначение страниц «выбрать тариф» и «узнать о подключении». Не смешивать бренд оператора и владельца партнерского сайта. Не распространять региональные значения на общую страницу по случайно определенному городу.

**Нюансы:** рекламная цена привязана к сроку и условию покупки оборудования в описании тарифа. Ее нельзя хранить только как перечеркнутое число. У открытой карточки `document.title` оказался пустым; это наблюдение DOM, не завершенный аудит серверного title или индексации.
