# T7–T8: публичные новости и общий предпросмотр

Статус: LOCAL CHECKED: 1048pass / 0fail / 1skip. Родительская задача [#534](https://github.com/Celtoman/astro-telekom/issues/534). Внешний выпуск и окончательная приёмка остаются T10–T11.

## Реализовано

Принятые список C, статья A и 404 собираются из общих компонентов. Список использует 12 материалов, страницы `/news/page/2`, категории — `/news/category/{slug}/page/2`. Единственная страница скрывает пагинацию. У статьи адрес `/news/{slug}`, категория не входит в URL. Карточка содержит одну ссылку, розовый чип и состояния hover/focus без изменения размеров. Нижняя голубая кнопка «Все новости» остаётся и при отсутствии связанных материалов. Общая главная получает три последние опубликованные новости, пустой блок скрывается. Legacy immutable snapshots не включают новый раздел автоматически.

Контент проходит общий чистый валидатор и renderer, включая безопасное экранирование текста, разрешённые ссылки, изображения и подписи. Meta description/title и OpenGraph поддерживают ручные исключения; изображения используют проверенные варианты. JSON-LD экранирует закрывающий `script`. Статья получает Article/NewsArticle, страницы списков — CollectionPage/ItemList, крошки — BreadcrumbList; автор и изображение появляются только при достоверных данных. Canonical пагинации указывает на саму текущую страницу. Основания: [Google Article](https://developers.google.com/search/docs/appearance/structured-data/article), [Google Breadcrumb](https://developers.google.com/search/docs/appearance/structured-data/breadcrumb), [OpenGraph](https://ogp.me/).

Предпросмотр использует настоящий renderer, CSS и шрифты сайта: 1440/834/390/320, «Черновик / На сайте», полная статья и карточки списка/главной, категория, настройки списка и 404. Он сначала сохраняет точную редакцию, не подменяет ошибку старым результатом и не включает посторонние черновики. Неопубликованные медиа читаются через авторизованный API и остаются в памяти браузера. Документ изолирован sandbox без скриптов. CSP разрешает точный хеш собственного CSS предпросмотра.
