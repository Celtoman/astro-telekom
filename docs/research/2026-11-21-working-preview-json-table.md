# SQL-проекция холодного предпросмотра · #630

Кандидат `743bca28` остаётся экспериментальным. Порог приёмки — снижение p95 до конца ответа минимум на 10% на каждом из четырёх маршрутов и положительная медиана пар в обеих половинах серии. У списка новостей p95 снизился на 8,45%, поэтому CI завершился кодом 2 после записи результатов.

Сравнили `a92f51a5` и `743bca28` на одном Linux runner с Node.js 22.23.4, PostgreSQL 18.6 и 79 миграциями. После прогрева выполнено 30 чередующихся пар на маршрут через NestJS/Fastify с выключенным переиспользованием результата. В синтетической базе 207 городов и 3 933 тарифа. Измерения относятся к локальному HTTP без внешнего HTTPS и браузера.

| Маршрут | p95 TTFB, мс | p95 до конца, мс | Снижение p95 | p95 SQL через Prisma, мс |
| --- | ---: | ---: | ---: | ---: |
| `/` | 642,57 → 561,11 | 642,93 → 561,45 | 12,67% | 150,16 → 38,65 |
| `/news` | 648,52 → 593,71 | 648,65 → 593,85 | 8,45% | 115,83 → 33,87 |
| `/news/story-0` | 649,38 → 545,17 | 649,50 → 545,30 | 16,04% | 112,15 → 30,67 |
| `/news/category/equipment` | 659,11 → 564,57 | 659,24 → 564,70 | 14,34% | 123,15 → 34,69 |

Девять пар `EXPLAIN (ANALYZE, BUFFERS, TIMING OFF)` точного запроса показали p50 104,19 → 26,51 мс и p95 104,58 → 30,18 мс. Обращения к буферам PostgreSQL снизились с 1127 до 383, физических чтений было 0. Для `/news` медиана сокращения полного времени по парам составила 16,17% и 12,33% в двух половинах серии.

Во всех 120 парах совпали байты HTTP-ответа. HTML совпал на четырёх маршрутах. Основная серия читала `RUNNING` до SQL ACK. Каждый запрос использовал один `/active` и один SQL-запрос с подтверждённым поколением и точным `validationId`. Совпали 12 дополнительных сценариев, включая строгую ошибку другого города, старый digest при замене с тем же ID, неполный seal и исторические исходники с повреждёнными ветками. Отдельно прошли 20 сравнений формы JSON и 23 теста.

Артефакт `working-preview-json-table-postgresql-ab` содержит обе серии.
