`City.seo` уже отсутствует в `prisma/schema.prisma`. Рабочий catalog содержит `seoByPath` для 4 018 маршрутов; предыдущая проверка C2 подтвердила семантическое равенство рабочего и опубликованного публичных каталогов, включая это поле. Компактный список тарифов не содержит `seo`, поэтому 108 неактивных тарифов проверялись по detail endpoint; для 3 805 опубликованных активных тарифов использован рабочий catalog.

Инвентарь через HTTP не заменяет SQL-проверку всех строк в момент удаления колонок: между чтением и миграцией возможна запись. Поэтому destructive migration должна брать блокирующую транзакционную блокировку, отказываться при любом `seo` кроме SQL `NULL`, JSON `null` или пустого JSON-объекта и только затем удалять поля. Сначала нужно убрать runtime-чтение и запись старых полей, подтвердить метаданные всех маршрутов и сохранить исторические `SitePublication` неизменными.
