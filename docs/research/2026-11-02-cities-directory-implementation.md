## Реализация

- `CitiesDirectory.astro` выводит общий `cities-directory-render.ts`; тот же renderer использует неактивный admin preview. Публичные и preview-стили берутся из одного Astro-компонента.
- Композиция: один H1, пояснение, поиск, статус, региональные группы. Декоративный hero/радар, карточки статистики, callout покрытия и FAQ удалены. Для CITIES больше не объявляется локальная секция `faq`: шапка/футер используют штатную городскую навигацию помощи.
- Данные — каталог соответствующего снимка. Группировка по `region.slug`, алфавитная сортировка регионов и городов по русской локали. Все городские ссылки присутствуют в серверном HTML и ведут на `/{location}`. Числа207/41 не являются константами реализации.
- Поиск фильтрует город или регион, нормализуя регистр, ё/е, пробелы. Совпадение региона показывает все его города; совпадение города — только найденные города внутри их регионов. Статус и региональные счётчики обновляются из результатов.
- Очистка и «Показать все города» сбрасывают только запрос и возвращают фокус в поле. Пустой каталог не показывает бессмысленный сброс. Пустая выдача не объявляет отсутствие сети. Текст запроса не вставляется как HTML.
- Поле изначально disabled и включается после инициализации. Без JavaScript весь каталог и обычные ссылки остаются доступны; фиктивно работающий поиск не показывается. В preview поиск/кнопки неактивны, ссылкам не назначается href, скрипты не добавляются.
- Тексты, slug и asset URL экранируются; городские slug проверяются до формирования ссылок. SVG поиска24px и очистки16px скачаны whole-node через Figma MCP в `public/images/cities-directory/`; исходные размеры SVG сохранены, очистка имеет область44×44px. Эти assets включены в локальный asset manifest preview. Phosphor Duotone: MIT-уведомление скопировано рядом с assets; [происхождение, размеры и SHA256](evidence/2026-11-02-cities-directory/assets.json) сохранены.

## Проверки и границы результата

Профильные7 файлов и повторный полный `pnpm check` прошли, без падений, отмен и пропусков, включая реальные PostgreSQL/Redis/Caddy rehearsals и Astro build/SEO/CSP. Полный gate выполнен в собственном процессе с CPU affinity2; настройки проекта и набор тестов не сокращались. Первый прогон без Docker имел16 инфраструктурных падений и одну устаревшую проверку прежнего H1. После запуска Docker владельцем и обновления проверки итоговый прогон зелёный. Полные численные результаты фиксируются только в [TEST_COVERAGE](../TEST_COVERAGE.md), [метаданные проверки](evidence/2026-11-02-cities-directory/validation.json) сохраняют команды и идентичность журнала. Проверки включают реальную Astro-сборку CITIES, состав ссылок и отсутствие локального FAQ, изоляцию preview и CSP.

При локальной приёмке 2 ноября внешний deployment, push, CMS-публикация и изменение production-данных не выполнялись. Внешний выпуск кода отдельно подтверждён [3 ноября](2026-11-03-cities-directory-release.md) в задаче #453; новая CMS-публикация не создавалась. Физические устройства, Safari/Firefox, озвучивание скринридером и мобильная экранная клавиатура не проверены. Новых несогласованных продуктовых находок нет; ранее зарегистрированные предложения сохраняют свои границы.
