# Преимущества покупки и проверка адреса на странице роутеров

23 ноября 2026. Изменения по согласованию владельца внесены в [файл «Дом.ру — Блоки роутеров»](https://www.figma.com/design/uTSyCWdgg1TAb5wuoPdwFu?node-id=10-1770).

## Состав сборки

Первый экран → преимущества покупки → каталог → проверка подключения → сравнение моделей → Mesh → консультация → FAQ. Ранее использовавшийся блок «Получение и настройка» и четыре его экземпляра перенесены на [архивную страницу](https://www.figma.com/design/uTSyCWdgg1TAb5wuoPdwFu?node-id=31-1202).

- [Преимущества покупки](https://www.figma.com/design/uTSyCWdgg1TAb5wuoPdwFu?node-id=2927-51). Блок использует карточки CMP-0046 и пиктограммы ремонта и поддержки из UI Library. Две карточки стоят в ряд на Desktop и Tablet, в колонку на 390 и 320 px. Формулировки адаптированы для сайта партнёра по мотивам [раздела оборудования Дом.ру](https://msk.dom.ru/internet/equipment).
- [Проверка подключения](https://www.figma.com/design/uTSyCWdgg1TAb5wuoPdwFu?node-id=2927-326). Четыре связанных варианта [BLK-0036 из UI Library](https://www.figma.com/design/AZQBtC5Pew2bjyvUFHIHEs?node-id=2561-754). Тот же компонент задокументирован для страницы проверки скорости.

## Проверка в Figma

Просмотрены экспорты обоих блоков на 1440, 834, 390 и 320 px. Ширина контента составляет 1360, 720, 358 и 288 px соответственно. Актуализированы обложка, карта и порядок страниц файла.

Сверены исходные размеры, видимость и мастер-компоненты сохранённых секций. Проверены 32 действия по клику, по восемь в каждом адаптиве, и наличие их целей в соответствующих сборках. Кнопка проверки адреса отображается в исходном библиотечном состоянии. Отправка адреса и сценарий результатов в этой версии макета отсутствуют.
