# HOME Hero 1d: локальная приёмка

Дата: 13 октября 2026 года. Задача [#277](https://github.com/Celtoman/astro-telekom/issues/277), адресная ссылка [#276](https://github.com/Celtoman/astro-telekom/issues/276). [Утверждённый паспорт и алгоритм замены](../plans/2026-10-13-home-hero-1d-contract.md). Это проверка локального кода; push, CI, внешний deployment и CMS-публикация не выполнены.

## Проверенный результат

- HOME 2.0.0 использует отдельный Hero 1d и редактор восьми полей. Отдельной подписи поля поиска в CMS нет; доступное имя «Поиск города» системное. Заголовок — одно поле с инструментами выделения/снятия красного через `<red>…</red>`, фиксированный цвет `#e0231e`.
- Результаты появляются при вводе. Выбор результата, быстрого города или O01 даёт Selected; следующий CTA/Enter открывает CITY_HOME. Подпись «Найти город» сохраняется.
- До выбора «Проверить адрес» на `/` имеет `/moskva#address-check`, после выбора Казани — `/kazan#address-check`. В sessionStorage хранится ID `city-kazan`; после перехода `/kazan` и возврата `/` поле и ссылки восстанавливают Казань. O01 из Hero вернул Самару в Selected, оставив URL `/`.
- Проверены Focus, InputError с `aria-invalid=true`, NoResults, Results с фактическим количеством совпадений, Selected, ArrowDown/Enter, очистка и повторный выбор. Поиск нормализует регистр, пробелы и ё/е; регион участвует в фильтрации.
- Версия проходит через API catalog и renderer. HOME 1.0.0/исторические снимки сохраняют старый renderer; CITY_HOME остаётся 1.0.0. Неизвестная версия и небезопасные маркеры отклоняются.

## Проверки и их границы

Итоговый `pnpm check` завершился с кодом 0: lint/typecheck, Prisma validation, сборки API/web/admin и все тесты без падений, отмен или пропусков. Точное количество хранится в [TEST_COVERAGE](../TEST_COVERAGE.md). После gate код не менялся; дополнялась только документация.

`tests/home-hero-1d.test.cjs` проверяет закрытую грамматику маркеров, целые переменные, границы полей, версию, legacy и guarded PATCH. Реальный PostgreSQL 18 rehearsal миграции 0060 подтверждает одну новую ревизию, before/after, сохранение ID/позиции/видимости, неизменность CITY_HOME/публикации, отказ неизвестной версии и повтор без потери поздней правки. Обратное изменение выполнено новой рабочей ревизией; универсальный интерфейс rollback не добавлялся. Seed проверен на свежей базе и повторном запуске.

Браузер проверял настоящий локальный Astro renderer с синтетическим опубликованным каталогом из 14 городов. Это не live-каталог и не проверка покрытия/доставки заявки. В редакторе использовался fixture HTTP API: выделение/снятие маркеров, безопасный цветной preview, отправка только восьми полей с expectedWorkingRevision. Реальный production PATCH из браузера не выполнялся; его защиту проверяет серверный тест.

Ширины 1440/834/390/320 px не имеют горизонтального переполнения. Desktop card — 1360 × 438, tablet — 720 × 780; mobile при ширине 390 — 358 × 806. Мобильная высота зависит от переноса текста, не фиксируется: явный перенос третьего описания сохранён. Короткие соединители шагов, responsive SVG 40/32/24 px и строки быстрых городов сверены визуально. Для мобильного screenshot использован touch/mobile browser context. Без JavaScript поиск и кнопка отключены, реальные ссылки быстрых городов и справочника доступны.
