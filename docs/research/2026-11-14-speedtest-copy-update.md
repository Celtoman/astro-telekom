# SPEED_TEST: обновление согласованного контента

Статус: COPY_APPLIED / LIBRARY_PUBLISHED / SCREENS_UPDATED / VERIFIED. Задача [#600](https://github.com/Celtoman/astro-telekom/issues/600). Визуальная приёмка владельцем новой редакции остаётся отдельным шагом.

## Изменения

- Применены полные тексты блоков подготовки, показателей, задач, факторов, диагностики и обращения в поддержку — 24 адаптивных оригинала.
- В данных для поддержки сохранено «пинг и джиттер, если он показан». В карточке больших файлов явно указано: «Теоретический расчёт для файла размером 1000 МБ».
- В шестой карточке подготовки «Запишите условия проверки» иконка Wi-Fi заменена на опубликованный CMP-0036 «Документ» из общей UI Library; component key 14df537cc5005299b591030ba6b014278dd588db.
- В четырёх первых экранах удалён только текст «OpenSpeedTest · новая вкладка» под измерителем. H1, название сервиса, кнопка и URL запуска сохранены. Высоты первого экрана уменьшились на 32 px.
- Белая основа, чередование поверхностей, типографика, сетки и состав компонентов сохранены. D/T-карточки выровнены по высоте внутри рядов через minHeight и HUG. Высота поддержки Desktop 400×340 совпадает с соседним списком.
- Восемь мобильных лент получили одинаковую высоту карточек под новый максимальный объём текста. Gap 16 px и видимый край следующей карточки сохранены; акценты вне лент.
- В новых текстах Wi-Fi использует неразрывный дефис, единицы Мбит/с и МБ/с не разрываются после косой черты. На 320 px формула делится на две смысловые строки.

## Публикация и проверка

Очищенный исходный файл сохранил девять страниц. Через встроенный браузер выполнены Publish 25/25 для контента и затем Publish 20/20 для неразрывного Wi-Fi. В Screens оба обновления применены через Manage libraries → Updates → Update all только на текущей странице, без «Show updates for all pages». Последнее подтверждение UI: «Successfully updated assets». Общая UI Library не публиковалась; профильные компоненты не переносились копированием.

Финальная проверка:
- 44/44 раздела Screens совпали с исходным примером по нормализованным деревьям свойств: текст, оформление, геометрия, styles, variables, component keys и действия.
- Все 24 набора текстовых полей совпали с согласованной редакцией; мобильные подсказки и технические неразрывные символы учтены отдельно.
- Все 468 экземпляров Screens связаны с remote masters; отсутствующих mainComponent нет. 86 разных component keys, включая документ.
- Отсутствующих fonts/styles/variables нет; шрифт Geist сохранён.
- Внешние промежутки по 24 px, включая FAQ → футер. В изменённых информационных блоках непреднамеренных выходов нет; прежние декоративные выходы адресного блока сохранены.
- Визуально просмотрены полные PNG всех четырёх ширин после последнего обновления. В исходном файле не осталось лишних новых вариантов.
- MD обновлён; ответы FAQ и сквозные блоки сохранены. README не требует изменения: код, runtime и публикация сайта не затронуты.

Это проверка макетов и библиотечных связей. Реальный замер, внешние переходы, звонки, touch-жесты в готовом сайте и пользовательские сессии не выполнялись.
