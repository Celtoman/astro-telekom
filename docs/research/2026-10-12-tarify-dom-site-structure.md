# Структура действующего tarify-dom.ru

Дата проверки: 12 октября 2026 года. Статус: исследование действующего источника для согласования новой структуры; не утверждённый перечень страниц новой версии.

## Решение владельца и границы

Владелец поручил сначала согласовать структуру сайта, затем структуру блоков главной. За основу выбран его действующий сайт [tarify-dom.ru](https://tarify-dom.ru/). Ранее составленный [канон проекта](../site-structure.md) используется для сопоставления, а не как автоматически выбранная основа новой структуры.

Исследование не разрешает менять URL, выпускать новые страницы, переносить блоки в код или публиковать сайт. Тарифные цены, маркетинговые обещания и сведения о провайдере не проверялись на достоверность; здесь изучаются роли страниц, вложенность и ссылки.

## Метод и охват

- Главная прочитана через web и Firecrawl; далее сделаны прямые HTTP GET и разбор исходного HTML. Firecrawl map использован для discovery, итоговые численные значения рассчитаны по XML sitemap, а не по выдаче map.
- [robots.txt](https://tarify-dom.ru/robots.txt) указывает [sitemap_index.xml](https://tarify-dom.ru/sitemap_index.xml). Прочитаны все восемь дочерних карт; считались только `url/loc` пространства имён sitemap, без image loc.
- Проверено содержимое 42 HTML-страниц с HTTP 200: главная, десять общих страниц, три юридических документа, семь городских страниц, шесть тарифных страниц, пять моделей оборудования и десять публикаций. Два дополнительных пробных адреса вернули HTTP 404.
- Городские примеры: Москва, Казань, Алейск; дополнительно по автоматическому правилу выбран минимальный, медианный и максимальный размер каталога среди городов с совпадающим sitemap-префиксом — Алексеевка (3 тарифных записи), Усолье (20), Обь (28). Сосновый Бор изучен отдельно из-за различий slug. Эти города не являются приоритетами переноса; реестр охватывает URL всех 207 городов.
- Тарифные примеры включают интернет, интернет+ТВ, пакет с кинотеатрами, два общих ТВ-тарифа и тариф Соснового Бора. Проверена структура страниц, а не работа расчётов или отправки заявок.
- Меню и Footer разобраны по точным контейнерам `data-elementor-type=header/footer`; ссылки карточек не считались глобальной навигацией. Проверялись href и соответствующие id; интерактивные модалки не открывались.

Доказательства: [полный реестр sitemap](evidence/2026-10-12-tarify-dom-structure/sitemap-urls.csv) и [проверенные HTML-страницы](evidence/2026-10-12-tarify-dom-structure/checked-pages.csv). `NOT_CHECKED` означает, что URL перечислен в sitemap, но HTTP и содержимое этой страницы отдельно не проверялись. Sitemap не доказывает полноту всех существующих URL или индексирование в поисковых системах.

Тарифная группа содержит 3859 записей с двухуровневым path и два общих ТВ-тарифа. Числа относятся к записанному sitemap-срезу, а не к количеству проверенных действующих предложений. ## Фактические типы страниц

| Роль | URL или шаблон | Наблюдение |
| --- | --- | --- |
| Федеральная главная | `/` | Выбор города, проверка адреса и обзор провайдера; конкретного городского каталога нет. |
| Городская главная и каталог | `/{citySlug}` | Например, `/kazan`, `/moscow`; один длинный landing с тарифными группами и информационными секциями. |
| Детальный городской тариф | `/{citySlug}/{tariffSlug}` | Например, `/kazan/giga-300-internet`; тариф расположен непосредственно под городом, без промежуточного каталога в URL. |
| Два общих ТВ-тарифа | `/kabelnoe-televidenie-obshhij-tarif`, `/cifrovoe-televidenie-obshhij-tarif` | На них ведут ТВ-карточки городских страниц; город в URL отсутствует. |
| Проверка подключения | `/podklyuchenie-po-adresu` | Общая функциональная страница с проверкой адреса и пояснениями. |
| Города и покрытие | `/goroda-obsluzhivaniya-domru` | Общий список городов; H1 объединяет города и карту покрытия. Отдельный URL карты не обнаружен в sitemap и изученной навигации. |
| Техническая поддержка | `/tekhpodderzhka-dom-ru` | Общая информационная страница с каналами связи. |
| Вопросы и ответы | `/faq` | Общая страница помощи. |
| Проверка скорости | `/proverit-skorost-interneta` | Общая страница инструмента. Работоспособность самого измерения не проверялась. |
| Личный кабинет | `/lichnyy-kabinet-dom-ru` | Информационная страница партнёра; основное действие ведёт на `https://dom.ru/user/login`. Собственная авторизация абонента этим не подтверждается. |
| Официальный сайт | `/official-site-domru` | Информационная страница партнёра с переходом на `https://dom.ru`. |
| Wi-Fi роутеры | `/wifi-router` | Общая посадочная с четырьмя моделями. |
| ТВ-приставка Movix | `/movix` | Общая посадочная с одной моделью приставки. |
| Модель оборудования | `/oborudovanie/{equipmentSlug}` | Пять отдельных страниц: четыре роутера и Movix Pro 2023. Общий listing `/oborudovanie` в sitemap не объявлен. |
| Новости и акции | `/akcii-domru` | Один общий listing для двух тематик. |
| Отдельная публикация | `/novosti/{slug}`, `/akcii-i-skidki/{slug}`, `/bez-rubriki/{slug}` | Десять страниц; отдельный блог в sitemap и изученном меню не обнаружен. |
| Юридические документы | `/soglasie`, `/policy`, `/politika-obrabotki-faylov-kuki` | Три общих документа из Footer. |

Все конкретные общие URL в таблице открыты и получили HTTP 200. Шаблоны определены по полному sitemap и проверенным примерам; это не утверждение, что каждый экземпляр маршрута был открыт.

## Навигация

### Федеральная главная

Основное меню: «Подключить Дом.ру» → `/#podkl`; «Техподдержка» → `/tekhpodderzhka-dom-ru`; «Вопросы и ответы» → `/faq`; «Новости» → `/akcii-domru`; «Личный кабинет» → `/lichnyy-kabinet-dom-ru`; «Официальный сайт» → `/official-site-domru`.

Верхние действия ведут на общие проверку адреса и проверку скорости. Верхнее действие поддержки и обратный звонок представлены popup-ссылками Elementor. Выбор города содержит популярные города, поиск и полный список ссылок. Поисковая логика и автоматическое определение региона не проверялись.

### Городская страница

В проверенных примерах тарифные пункты являются якорями текущей страницы:

- «Домашний интернет» → `#internet`;
- «Интернет + ТВ» → `#internetTV`;
- «Цифровое ТВ» → `#TV`;
- «Подключить Дом.ру» → `#podkl`.

Новости, помощь, поддержка, личный кабинет и официальный сайт ведут на общие страницы. В sitemap нет самостоятельных городских категорий вида `/{city}/tarify-domashniy-internet` или `/{city}/vse-tarify-domru`; изученные меню их также не используют. Подробные карточки ведут на тарифные detail URL; кнопки подключения открывают popup по href.

### Footer

Общий Footer содержит телефоны подключения и поддержки, заявку, информационные разделы, проверку адреса/скорости, города, новости, роутеры, Movix, социальные ссылки и три юридических документа. Ссылка «Как подключиться» ведёт на `/#podkl`, в том числе с городской страницы.

## Композиции страниц как контекст структуры

Это наблюдение источника, а не решение переносить все его блоки.

**Главная:** вводный экран → проверка адреса → выбор города → навигация по услугам и сервисам → информация об операторе и технологиях → преимущества → этапы подключения → стоимость подключения → обзор тарифных линеек → оборудование → FAQ → акции и новости → Footer.

**Город:** вводный экран → проверка адреса/консультация → подбор по устройствам, ТВ и интересам → интернет+ТВ → интернет → ТВ → сравнение → этапы подключения → Movix → оборудование → преимущества → отзывы → другие города → местные контакты → FAQ → Footer. Подбор присутствует в HTML и интерфейсных элементах; качество алгоритма не проверялось.

**Тариф:** основные параметры и цена → оборудование → дополнительные возможности/описание при наличии → проверка адреса → другие тарифы города → FAQ. Три основных городских тарифных примера имеют одинаковый набор H2; часть условных секций отсутствует у общих ТВ-тарифов и проверенного тарифа Соснового Бора.

## Отличия от нынешнего канона проекта

| ТВ без интернета | Два общих detail URL | Первый этап тарифной модели описывает интернет и интернет+ТВ; такой общий маршрут не включён. |
| Проверка адреса | Общий `/podklyuchenie-po-adresu` | Общая `/karta-pokrytiya-provaydera` и будущие городские проверки — иная структура. |
| Города/покрытие | Один общий `/goroda-obsluzhivaniya-domru` | Две обязательные общие страницы: города и покрытие. |
| Поддержка | Общая `/tekhpodderzhka-dom-ru` | Предусмотрены будущие городские страницы поддержки. |
| Оборудование | Две посадочные и пять моделей | Предусмотрены `/oborudovanie` и категории; detail моделей отдельным типом не перечислены. |

Отсутствие URL в sitemap и изученных меню не доказывает, что скрытый или исключённый из sitemap адрес не существует. Для утверждения переноса важны подтверждённые разделы и явно согласованные дополнения.

## Особенности источника, требующие учёта

- Для Соснового Бора городская карта объявляет `/sosnovyj-bor`, а 19 тарифных адресов используют `/sosnoviy-bor/…`. Проверены HTTP 200 у первого адреса и `/sosnoviy-bor/giga-300-internet`; `/sosnoviy-bor` возвращает HTTP 404. Поэтому соответствие города тарифу нельзя строить только по одинаковому path-префиксу. Решение о новых slug и redirects не принималось.
- `/sitemap` возвращает HTTP 404; XML sitemap доступен. HTML-карта сайта не обнаружена в объявленном реестре и навигации.
- Дублированная sitemap-запись не учитывается как отдельная страница. Эти наблюдения относятся к действующему источнику и не означают дефект реализации astro-telekom.

## Решение по итогам обсуждения 12 октября

На текущем этапе владелец утвердил одну основную страницу каждой локации, без отдельных страниц категорий «Домашний интернет», «Интернет + ТВ» и «Цифровое ТВ». Отдельные страницы конкретных тарифов сохраняются по действующему контракту. Это не утверждение состава блоков действующего сайта: блоки будут переработаны и согласованы позднее. Наблюдения источника выше сохраняются как датированный срез.

Следующее согласованное решение: пока сохраняются две отдельные общие страницы ТВ-тарифов — кабельного и цифрового телевидения — без привязки к локации. Новые URL, блоки и реализация этим решением не утверждены.

По оборудованию согласованы только общие страницы «Роутеры» и «Movix». Отдельные страницы моделей оборудования на текущем этапе не нужны. Наличие пяти таких страниц у источника, описанное выше, не является решением переносить их в новую структуру.

Новости и акции согласованы как два самостоятельных общих раздела, каждый со своим списком и отдельными страницами публикаций. Это согласованное отличие от общего listing действующего сайта. Окончательные URL и блоки ещё не утверждены.

Общая самостоятельная страница адресной проверки не сохраняется. Владелец уточнил: внутри каждой локации добавляется отдельная страница проверки подключения по адресу, в дополнение к основной странице и страницам конкретных тарифов. Точный slug, блоки и реализация пока не утверждены.

Отдельная общая страница «Города обслуживания» со списком всех локаций сайта согласована к сохранению. Точный URL и состав блоков новой версии пока не утверждены.

Владелец также подтвердил сохранение отдельной общей страницы «Карта покрытия», наряду со справочником локаций и проверкой адреса внутри каждой локации. Способ представления покрытия, блоки и точный URL новой версии пока не утверждены.

«Техподдержка» также согласована как отдельная страница внутри каждой локации, по аналогии со страницей проверки подключения. Общая страница техподдержки в новую структуру не переносится; точный slug, блоки и реализация ещё не утверждены. Наблюдение об общей странице действующего источника выше сохраняется как датированный срез.

«Вопросы и ответы» сохраняются одной общей страницей для всего сайта. Её точный URL и блоки ещё не утверждены; это решение о самостоятельной странице, а не о FAQ-блоках других шаблонов.

## Следующее согласование

Необходимо утвердить остальные сохраняемые типы страниц и точные URL. Сохранение старых URL или переход на новые адреса требует отдельной таблицы соответствий, в том числе для разделённых новостей и акций. Затем можно утверждать меню и состав блоков каждого шаблона.

Этот отчёт фиксирует исходный сайт. Решение «взять за основу» не означает автоматически перенести все текущие тексты, UX, цены, URL или спорные особенности. Новые релизные границы и окончательный канон утверждаются владельцем отдельно.
