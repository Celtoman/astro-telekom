# T5: список и редактор новостей

Статус: LOCAL WORKSPACE CHECKED / DEPENDENT END-TO-END ACCEPTANCE PENDING. Задача [#534](https://github.com/Celtoman/astro-telekom/issues/534). Этапы T6–T11 остаются открытыми; публикация реальных перенесённых материалов не разрешена автоматически.

## Реализовано

- `/news`, `/news/new`, `/news/edit`: существующий persistent AdminWorkspace, cookie-auth и Tailwind/shadcn/React Aria. Данные читаются через API; SSR не содержит пользовательского содержимого. Новое создание получает постоянный client ID в URL до первого POST.
- Список: поиск с debounce, фильтры категории/состояния, даты, серверная пагинация по 25, table/mobile list, честные initial/empty/error/stale states. Возврат сохраняет фильтры и позицию. Настройки списка и управление категориями подключаются в T6.
- Редактор: содержание слева и параметры справа; на узком экране параметры следуют за текстом. Ограниченный Tiptap, отдельные cover/body/social media, категория с inline-create, дата и неизменный при правке заголовка slug, необязательные реальный автор и источник, auto/manual related, SEO/OG defaults/overrides. Ручной picker читает serving projection, включая live-материалы с новым draft.
- Автосохранение сериализует запросы и подтверждает захваченный текст. Ответ старого запроса не удаляет новый ввод или его recovery. 409 останавливает запись до явного сравнения. Local recovery привязан к аккаунту, сайту, материалу и отдельному writer; TTL 7 суток. Ошибка/ограничение localStorage отображается, серверное сохранение продолжает работать.
- История: опубликованные версии и 20 checkpoint-редакций; сравнение и restore только в draft. No-op checkpoint закрепляет существующую редакцию без создания дубля. Ввод во время восстановления не сбрасывается ответом сервера: требуется сравнение.
- Review показывает revisions, зависимость новой категории, затронутые адреса, aliases и ошибки. Publication сохраняет operation ID до терминального результата; неопределённый ответ повторяет ту же операцию. Progress другого выпуска исключён. Редактирование следующего draft не блокируется. Полный shared preview добавляется в T8.
- Общий экран публикации явно исключает редакционные черновики. В разделе новостей верхнее действие названо «Публикация других разделов». Explicit logout удаляет recovery только после успешного завершения сессии; dirty logout требует явного выбора, 401 recovery не удаляет.

## Проверено на локальных синтетических данных

Чистые state-machine tests покрывают ввод во время запроса, retry, 409, recovery поверх более свежего сервера, checkpoint, scoped storage, сохранение фильтров и изоляцию publication progress. API projection tests проверяют serving-only related options и unavailable selections. SQL rehearsal подтвердил no-op checkpoint без новой revision; старый store воспроизвёл ошибку до исправления.

Browser smoke во встроенном Chromium: реальный вход в локальный API, список, изменение заголовка без смены slug, сохранение, конфликт двух вкладок, явный выбор серверной редакции, просмотр истории и восстановление исходной редакции. Синтетический материал остаётся draft; реальных внешних новостей не публиковали.

Визуально просмотрены 1440/834/390/320 в тёмной теме; DOM scrollWidth равен clientWidth на всех четырёх ширинах. На 320 проверены поля категории/даты/slug и видимый клавиатурный фокус. Это viewport emulation, не проверка физического touch-устройства или screen reader. Светлая тема, 200%/400% zoom, загрузки/кроп в полном редакторе, uncertain activation и shared preview остаются в T10. Static Impeccable detect четырёх новых UI-модулей: нет findings; это не заменяет визуальную и функциональную проверку.
