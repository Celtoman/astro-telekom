# Открытие SEO-шаблонов и Sitemap · #630, этап 3.4

Настройки обоих экранов открываются отдельным чтением без расчёта каталога. SEO показывает проверенный список и SEO/OG выбранного URL после действия «Проверить маршруты». Sitemap загружает проверенные строки после действия «Проверить маршруты Sitemap» и строит XML по кнопке с учётом несохранённых исключений. Полные маршруты API и условия сохранения поддерживаются для прежних клиентов.

## Эквивалентность

- Полный список Sitemap совпал по всем строкам и диагностике. Совпали все страницы группы городов и крайние страницы остальных групп. XML использует тот же origin, порядок и набор URL после применения `noindex` и ручных исключений. Независимое чтение трёх дочерних XML подтвердило все 3527 абсолютных адресов без дублей. Тест публичной сборки отдельно проверяет один canonical на точный URL у индексируемой страницы и отсутствие canonical у `noindex`.
- SEO-проверка вернула те же канонические пути, SEO/OG, `noindex` и предупреждения для выбранного из списка URL. Исторический снимок без `seoByPath` сохранил `null` для опубликованной детали.
- Точная рабочая ревизия обязательна для проверки. При продолжении SEO-проверки можно закрепить ID опубликованного снимка. Локальный контроллер `/active` успешно указал на уже обслуживаемый `RUNNING`, хотя в SQL существовал другой `SUCCEEDED`. Неверный digest вернул 503, несовпадающий ожидаемый ID — 409.
- Полная проверка находит ошибки вне выбранного URL. Переход в `NOINDEX` требует подтверждения точного числа маршрутов, сохранение ручных исключений повторно проверяет рабочую ревизию и полный каталог.

## Точечное чтение обслуживаемого основания

Кандидат `5d014c36` переиспользует точечную выборку редакционных данных из обслуживаемого снимка при проверке Sitemap с заданной рабочей ревизией. Используются имеющийся флаг проекций и static provider. Валидация, построение рабочего каталога, поиск, пагинация, черновые исключения и полный XML проходят прежний путь. Для дешёвых повторных страниц нужен проверенный результат фонового расчёта с доказанной актуальностью по рабочему источнику, опубликованному основанию и версии правил.
