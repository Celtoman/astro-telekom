Журнал HTTP fixture позволяет сверить запросы HTML независимо от окна событий Chrome DevTools. В исходной сборке на обычном переходе запрашивался HTML целевого маршрута. При клиентских переходах новой сборки остались запросы к API и загрузка JS-модулей по необходимости. Отдельно найден переход из свёрнутого меню React Aria, который открывал новый документ. После подключения RouterProvider к общему guard он перестал загружать целевой HTML.

Проверены переход из списка с `returnTo` в редактор новости, сохранение введённого текста при отмене ухода, отмена и подтверждение «Назад», возвращение «Вперёд» по исходному URL и отдельный запрос документа `/preview`. В браузерной консоли на этих сценариях не было ошибок и предупреждений. В итоговой сборке проверены перенос фокуса на якорь публикации, закрытие меню на ширине 390 px, баннер при несовпадении версии с последующим запросом нового HTML и возврат на отдельный экран входа после 401.
