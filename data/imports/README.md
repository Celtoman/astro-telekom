# Источники импорта

`cities.xlsx` — канонический исходный справочник из 207 городов для первоначальной загрузки сайта Дом.ру. Файл проходит штатную validation-фазу целиком; его структура защищена тестом `tests/city-import.test.cjs`.

Импорт выполняется только через административный HTTP API:

```bash
# API должен быть запущен, ADMIN_API_TOKEN — совпадать с его окружением
pnpm cities:import
pnpm cities:import -- --apply --actions=data/imports/city-actions.json
```

Первая команда сохраняет validation run и выводит счётчики. Вторая требует JSON action map с явным `create`, `update` или `skip` для каждого кандидата. Решения автоматически не подставляются. Существующий город сохраняет свой статус; новый создаётся в `DRAFT`. Его единственная `PUBLISHED` HOME-shell связана через `templateId` с общим CITY_HOME 3.0.0 и не получает семь локальных блоков. Если у сайта уже есть ADDRESS-шаблон, создаётся и соответствующая ADDRESS-shell. Строки с `skip` не изменяются. Сайт можно задать через `CITY_IMPORT_SITE_SLUG`.

XLSX является входным источником, а не runtime-базой. После apply источник правды для приложений — PostgreSQL; web во время `astro build` создаёт `/{location}` для города, включённого в успешно опубликованный снимок. Импорт сам по себе не публикует новые города или сайт; готовность и явная CMS-публикация проверяются отдельно.
