# Источники импорта

`cities.xlsx` — канонический исходный справочник из 207 городов для первоначальной загрузки сайта Дом.ру. Файл проходит штатную validation-фазу целиком; его структура защищена тестом `tests/city-import.test.cjs`.

Импорт выполняется только через административный HTTP API:

```bash
# API должен быть запущен, ADMIN_API_TOKEN — совпадать с его окружением
pnpm cities:import
pnpm cities:import -- --apply --actions=data/imports/city-actions.json
```

Первая команда только сохраняет validation run и выводит счетчики. Вторая требует JSON action map с явным `create`, `update` или `skip` для каждого кандидата и применяет импорт. Решения автоматически не подставляются. Статусы существующих городов импорт не меняет; новый город и его единственную bootstrap-страницу `HOME` создает в `DRAFT`. Сайт можно явно задать через `CITY_IMPORT_SITE_SLUG`.

XLSX является входным источником, а не runtime-базой. После apply источник правды для приложений — PostgreSQL; web во время `astro build` создает `/{location}` для каждого города, который отдельно переведен администратором в `PUBLISHED`.
